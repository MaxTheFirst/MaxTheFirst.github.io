Проблемы

В институте во время сессии часто нужно быстро получить обновлённый вариант билетов.

На работе нужен отчёт от коллеги. Ты знаешь, что он его уже правит — но когда он закончит? Где актуальная версия?

При работе с проектами команда использует разные платформы: кто-то отправляет файлы в Telegram, кто-то в Google Drive, кто-то по почте. Документы рассеиваются, теряются версии.

Есть решение!

Решение

PDFShare — это удобное пространство для хранения, обновления и расшаривания PDF-документов с автоматическими уведомлениями в Telegram. Вы просто загружаете файл, а все подписчики получают сообщение о новой версии.

Техническое описание

  • Frontend: React (TypeScript)
  • Backend: Node.js (TypeScript)
  • Хранилище: Google Cloud Storage
  • База данных: PostgreSQL
  • Авторизация: Telegram (одноразовые токены из бота)
  • PDF Viewer: react-pdf
  • Уведомления: Telegram Bot (webhook mode)

Пользовательские сценарии

📘 Студент

Загружает билеты/работы, делится ссылкой с группой. Преподаватель внёс правки в программу — студент загружает новую версию, а всем подписчикам приходит уведомление в Telegram.

📊 Офисный сотрудник

Делится отчётом с отделом. При обновлении файла коллеги получают уведомления — больше никаких «скинь ещё раз»/«ГДЕ ОТЧЕТ!?».

🤝 Команда проекта

Хранит договоры, спецификации, схемы. Папки можно расшаривать публично или точечно по подписке.

Описание API

Основные endpoints

Endpoint Method Description
/api/auth/telegram-login/:token GET Логин пользователя по одноразовому токену
/api/auth/me GET Получение данных текущего пользователя
/api/folders GET Список папок пользователя
/api/folders POST Создание новой папки
/api/folders/:id DELETE Удаление папки
/api/files POST Загрузка файла
/api/files/:id GET Получение файла
/api/files/:id/share POST Поделиться файлом
/api/subscriptions POST Создание подписки
